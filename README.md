# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is enabled on this template. See [this documentation](https://react.dev/learn/react-compiler) for more information.

Note: This will impact Vite dev & build performances.
You can also try [the experimental native React Compiler support in plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md#rust-react-compiler) by using `compiler: true` in the plugin options instead of using the Babel plugin.

# 🔎 FoundIt — Campus Lost & Found

**Lost something? Find it with FoundIt.**

FoundIt is a campus lost and found platform designed to help university students report missing belongings, discover found items, and reunite people with their lost possessions — all in one place.

## ✨ Key Features

- 🔍 **Smart Search:** Find items using search and filters.
- 📦 **Lost & Found Reports:** Report lost or found belongings.
- 🖼️ **Item Details:** View descriptions, photos, dates, and locations.
- 👤 **User Accounts:** Manage your personal reports.
- 🔄 **Status Tracking:** Track items until they are recovered.
- 🎯 **Similar Item Matching:** Suggest potentially related reports using predefined rules.
- 📱 **Responsive Design:** A smooth experience across desktop and mobile.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git & GitHub

## 🎯 Our Mission

To make campus communities more connected by making lost belongings easier to find and return.

## 👥 Team

Developed by a team of 4 students as part of the **Digital Egypt Pioneers Initiative (DEPI)**.

## 🚧 Project Status

Currently under development.
