# 🔎 FoundIt — Campus Lost & Found

**Lost something? Find it with FoundIt.**

FoundIt is a campus lost and found platform designed to help university students report missing belongings, discover found items, and reunite people with their lost possessions — all in one place.

## ✨ Key Features

- 🔍 **Smart Search:** Find items using search and filters.
- 📦 **Lost & Found Reports:** Report lost or found belongings.
- 🖼️ **Item Details:** View descriptions, photos, dates, and locations.
- 👤 **User Accounts:** Manage your personal reports.
- 🔄 **Status Tracking:** Track items until they are recovered.
- 🎯 **Similar Item Matching:** Suggest potentially related reports using predefined rules.
- 📱 **Responsive Design:** A smooth experience across desktop and mobile.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git & GitHub

## 🎯 Our Mission

To make campus communities more connected by making lost belongings easier to find and return.
